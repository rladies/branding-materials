# Legacy R-Ladies Branding (pre-2026)

This directory contains the original R-Ladies branding materials used before the 2026 rebrand to **RLadies+**.

## Old brand specs

- **Colour:** `#88398a` (Purple) and `#a7a9ac` (Gray)
- **Font:** Open Sans
- **Spelling:** R-Ladies

## Contents

- `logo/` -- Original R-Ladies logos
- `stickers/` -- Hex sticker designs
- `file-templates/` -- Word/PowerPoint templates
- `roll-up/` -- Roll-up banner designs

For current branding, see the [repository root](../).
