# RLadies+ Branding Materials

Official branding assets for **RLadies+** (formerly R-Ladies).

## Brand specs

| Element | Value |
|---------|-------|
| Primary colour | `#881ef9` (Purple) |
| Secondary colour | `#146af9` (Blue) |
| Tertiary colour | `#ff5b92` (Rose) |
| Neutral | `#2f2f30` (Charcoal) |
| Light | `#ededf4` (Lavender) |
| Headings font | Poppins (600) |
| Body font | Poppins (400) |
| Monospace font | Inconsolata |

Full details in [Branding-guidelines.pdf](Branding-guidelines.pdf) and [brand.yml](brand.yml).

## Quarto extension

For Quarto documents and presentations, use the [glamour](https://github.com/rladies/glamour) extension, which applies RLadies+ branding automatically.

## Spelling

- **RLadies+** -- preferred form
- `rladies` (no plus) only where special characters are not allowed (usernames, account names)
